# Power BI Project

This folder contains the complete **Power BI project files** for the Jotstar and LioCinema analysis.

## 📁 Project Files

### `Jotstar-LioCinema-PowerBI-Analysis.pbip`

Power BI Project file used to open and manage the report and semantic model.

### `Jotstar-LioCinema-PowerBI-Analysis.Report/`

Contains the Power BI report definition, including:

- Report pages
- Visual configurations
- Page layouts
- Filters
- Visual-level settings
- Report metadata

The report contains the following analysis pages:

1. **Home** – Project landing page and navigation
2. **Overview** – User and platform performance overview
3. **Content Analysis** – Content types, genres, languages and runtime
4. **Subscriber Analysis** – Subscription plans and subscriber behavior
5. **Content Consumption Analysis** – Watch time and consumption patterns

### `Jotstar-LioCinema-PowerBI-Analysis.SemanticModel/`

Contains the Power BI semantic model definition, including:

- Tables
- Columns
- Relationships
- Measures
- Calculations
- Data model metadata
- Cultures and other model configuration

## 🛠️ Technologies

- Power BI Desktop
- DAX
- Power Query
- Power BI Project (`.pbip`) format
