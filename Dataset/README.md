# Dataset

This folder contains the datasets used for the **Jotstar and LioCinema Power BI Analysis** project.

## 📊 Dataset Overview

The dataset contains information related to:

- Users and subscribers
- Subscription plans
- Content
- Content consumption
- Watch time
- User activity
- Platforms
- Devices
- Languages
- Genres
- User demographics

The data is used to analyze subscriber behavior, content availability, and content consumption across Jotstar and LioCinema.

## 📁 Files

### `meta_data.txt`

Contains the detailed **data dictionary** for the dataset, including:

- Column names
- Column descriptions
- Purpose/meaning of each field
- Relevant information required to understand the dataset

Please refer to `meta_data.txt` for the detailed description of individual columns.

## 🔗 Usage

The datasets in this folder are used as the source data for the Power BI semantic model.

The data is transformed and modeled in Power BI using **Power Query and DAX** before being used in the dashboard.

## ⚠️ Note

The dataset is provided for **analysis and learning purposes** as part of this Power BI portfolio project.
