# SQL Analysis – Jotstar & LioCinema

SQL analysis for the Jotstar & LioCinema Power BI portfolio project.

## Source

The project contains two databases:

- `LioCinema_db`
- `Jotstar_db`

Each contains `contents`, `subscribers`, and `content_consumption` tables.

The queries are written for MySQL 8+ and cover user, subscription, content, consumption, device, demographic, and plan-movement analysis.

10. Genre
11. Language

14. Device watch time
15. Average watch time per user
16. Watch time by age
17. Watch time by plan
18. Plan movements
19. Upgrades
20. Downgrades
21. Net upgrade/downgrade rate
22. Monthly subscriber acquisition
23. Monthly plan changes
24. Top genres using a window function
25. Device share using a window function
